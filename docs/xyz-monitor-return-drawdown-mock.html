What each name paid in pain for what it paid out

The table says where a name is now. The drawer sparkline shows the path. 2 · The diagonal  the one line that turns a scatter into a verdict

Best return = max drawdown

Above the dashed line a name made more than it ever gave back inside the window; below it the worst stretch was bigger than the best one. That is the whole read, and it is why the axes are laid out so that the line runs corner to corner: the eye finds above and below without arithmetic.

The Best / DD column is the same read as a number, so the sort can rank on it — a 3× is a name that paid three units for every unit of pain, whatever the absolute size of either.

Why the drawdown is measured from the running peak

A name that went +40% and then fell to +10% has a −21% drawdown, not −30 points of "given back" — the two are different questions. Gave back (best minus now) is in the table because it is what a holder feels; the drawdown on the axis is the path-dependent one, because the path is what a stop would have hit.

Both are stated in the readout with their dates, so a dot is never a number without a story.

3 · What we did not draw  two versions that looked right in a screenshot

Colour by sector, eleven hues, no legend on the plot.

Eleven categorical hues on a dark surface, none of them separable under deuteranopia, and the sector was never the question. The shipped colour is the sign of now — two hues, the app's own red/green pair, with the sign also printed in every label, readout and cell so colour is never the only carrier.

Drawdown as a negative x-axis, zero on the right.

Mathematically identical, and it puts the sweet spot top-right where every other quadrant chart in the app puts "leaders" — so it reads as "accumulation" at a glance and as "shallow drawdown" only on the second look. Deeper-to-the-right keeps the diagonal corner-to-corner and the quadrant words honest.

4 · What this pins down

The anchor is a UTC midnight, and the first bar on or after it is the base

Daily bars are keyed by UTC day, so "since March 3" resolves to the first close at or after 2026-03-03T00:00Z. A weekend anchor starts on the Monday and is not flagged; a first bar more than four days past the anchor is a listing that came after it and is drawn hollow, marked late, and starts at its own first close — it is in the picture but it is not the same race.

The live mark is today's point

Between daily-bar refreshes a name making its high right now would otherwise read as yesterday's close. The mark is folded in as the last point (replacing today's forming bar when one exists), so best, drawdown and now all move with the tape. The readout says live mark or last close so the source is never ambiguous.

Closes only, and the caption says so

The daily feed carries no intraday low, so the drawdown is close-to-close: a wick below the close is not counted. A study that quietly used highs for the numerator and closes for the denominator would flatter every name; this one uses closes for both and states it under the chart.

Labels route, dots never move

A dot's position is the data. Labels take the sector map's greedy layout — a free side, a leader line when it is not the default one, a page-colour halo — so a crowded board stays legible without a single dot being nudged. Past 45 names auto keeps the standouts on either axis and the best ratios; all and none override.

No route, no persistence, no server

The study is a pure function of /api/daily, already pinned public under the markets key, plus the live mark. Gating the tab can never strand a request; the anchor, label mode and sort live in this browser's localStorage and nowhere else.

Follows the Stocks | Crypto switcher

Same study, the other universe's closes. Crypto history on the wire is about 90 days, so an older anchor starts every coin late — the header counts them rather than drawing a full board that silently means something else.

5 · What it deliberately does not do

No benchmark-relative axis

"Best return vs the S&P" is a different chart (the Sectors leaders map already has one). Absolute return is what the question was about; a relative version can be a toggle later without moving a dot.

No bubble size

Volume as a third channel made the crowded board unreadable and answered nothing the question asked. Every dot is 10px; the hit target is 22px.

No intraday anchor

The finest anchor is a UTC day. An intraday version needs the hourly spine, which is per-name and lazily fetched; the daily one is on every page already.
